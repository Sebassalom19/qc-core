# QC-core: Software-Intensive Quantum Computing Core

### Propósito del repositorio QC-core 

La finalidad de este proyecto/repositorio es utilizar el paradigma de Sistemas Intensivos en Software en computación cuántica.

QC-Core busca mantener un orden al momento de hacer proyectos de computación cuántica, tomando un enfoque diferente al enfoque monolítico que se usa en la computación cuántica actual, donde la principal función de esta tecnología es analizar y verificar modelos matemáticos. Este repositorio busca crear una estructura en la ejecución cuántica, para así, tomarlo como un sistema modular, mantenible, y desacoplado, siguiendo el diseño de software conocido como Arquitectura Hexagonal, donde el dominio del sistema, los puertos y adaptadores son componentes separados que se relacionan, pero no se modifican, además de usar el patrón Pipes and Filters para organizar el procesamiento de datos cuánticos, garantizando su resiliencia.

### Pilares arquitectónicos

**Arquitectura hexagonal**

**Pipes and filters**

**Resiliencia y tolerancia a fallos**
